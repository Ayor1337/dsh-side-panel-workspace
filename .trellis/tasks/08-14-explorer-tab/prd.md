# 资源管理器标签页（文件树 + 内容预览）

## Goal

在 DSH 侧边抽屉插件中新增"资源管理器"标签：左侧为文件内容显示区，右侧为当前工作区的
文件树状图；点击树中的文件在抽屉顶部标签栏打开新的文件标签（内容在左、树状图在右）；
文件夹左键展开/折叠。让用户不离开聊天页即可浏览工作区文件。

## Background

用户原始需求（记录）：

> 我要制作一个资源管理器，资源管理器分为两个部分，首先是左侧是显示区，可以显示大多数的文本，
> 右侧则是一个树状图显示当前工作区的所有文件。在点击文件之后，会打开一个新的标签，新的标签仍
> 为文件的页面，并且打开文件内容显示在左侧，右侧依然是工作区树状图。树状图要求可以每个文件夹
> 可以通过左键展开和关闭。

已确认的产品决策：

- **D1 标签页结构**：抽屉级标签。点击文件后在抽屉顶部标签栏（与终端/浏览器并列）新增文件标签；
  资源管理器标签与每个文件标签的页面布局均为"左侧内容显示区 + 右侧工作区树状图"。
- **D2 工作区根目录**：树根跟随当前会话 cwd（复用现有 `ctx.sessions.list` 快照，
  会话/工作区切换时树自动切换）。
- **D3 树的范围**：全部显示（不排除 node_modules / 隐藏文件）；子目录按需懒加载
  （展开时才列目录），避免一次性递归列目录导致性能问题。
- **D4 重复点击同一文件**：聚焦已有标签（文件标签单例，与现有浏览器标签单例行为一致）。

## Requirements

- **FR1 资源管理器标签**：抽屉"+"菜单新增"资源管理器"项，打开资源管理器标签
  （单例，与浏览器一致）：左侧内容显示区（初始为空态提示"从右侧树中选择文件"），
  右侧为以当前会话 cwd 为根的文件树状图。
- **FR2 文件树**：树显示根目录下所有条目（含隐藏文件与 node_modules，不排除）；
  文件夹条目支持**左键点击**展开/折叠；展开时按需向宿主请求该目录的子项列表；
  目录优先、按名称排序。
- **FR3 点击文件开新标签**：左键点击树中的文件 → 抽屉顶部标签栏新增文件标签
  （标题为文件名）并自动激活；标签内左侧显示文件内容，右侧依然为工作区树状图；
  同一文件已打开时聚焦已有标签（D4）。
- **FR4 文本内容显示**：左侧以等宽字体、可滚动区域显示文本文件内容；
  二进制文件显示"不支持预览"提示；超大文件截断显示并提示（上限见 design.md）。
- **FR5 标签管理**：文件标签与资源管理器标签均可通过 chip 关闭按钮关闭；关闭行为与现有标签一致。
- **FR6 会话跟随**：会话/工作区切换导致 cwd 变化时，树自动重置并显示新 cwd 的树。
- **FR7 主题适配**：明/暗主题下界面配色正常（使用 DSH 主题 CSS 变量 --dsw-*）。

## Acceptance Criteria

- [ ] **AC1**：打开资源管理器标签，右侧出现以当前会话 cwd 为根的树，根目录条目可见
      （含隐藏文件与 node_modules 条目），左侧显示空态提示。
- [ ] **AC2**：左键点击文件夹行 → 展开显示子项；再次左键点击该文件夹行 → 折叠。
- [ ] **AC3**：左键点击文件行 → 抽屉标签栏新增以文件名命名的标签并激活；
      标签内左侧显示文件文本内容，右侧仍为树状图。
- [ ] **AC4**：再次点击树中已打开的文件 → 不新增标签，聚焦已有标签。
- [ ] **AC5**：点击二进制文件（如图片/可执行文件）→ 标签左侧显示"不支持预览"提示，不出现乱码。
- [ ] **AC6**：点击超大文本文件 → 显示文件开头部分并给出截断提示，页面不卡死。
- [ ] **AC7**：在终端中新建文件/目录后，折叠再展开其父文件夹，树中能看到新条目
      （懒加载按需刷新）。
- [ ] **AC8**：切换会话后树根随之切换为新会话的 cwd。
- [ ] **AC9**：明暗主题切换后资源管理器界面配色正常。
- [ ] **AC10**：文件标签与资源管理器标签均可通过 chip 关闭按钮关闭。

## Out of Scope

- 文件编辑 / 保存；图片等二进制内容预览；文件搜索；树状态跨刷新持久化（刷新后树回到
  折叠状态）；右键菜单；跨标签同步树的展开状态；多开资源管理器标签（单例）。
