# DSH 插件：聊天页右侧抽屉（终端 + 浏览器）

## Goal

为 DSH Web GUI 聊天页添加一个常驻的右侧抽屉，内含**终端**与**浏览器**两个功能。抽屉默认折叠，
由聊天页右上角的按钮控制；展开时占据独立右侧栏，聊天文字自动让位、不被遮挡。
以 out-of-tree 双半插件形式交付，可安装、可卸载，不影响产品其他功能。

## Requirements

### 功能需求

- **FR1 右上角开关按钮**：聊天页右上角（会话头部右侧工具区）常驻一个抽屉开关按钮；
  抽屉默认折叠，按钮不随折叠消失。
- **FR2 展开 / 折叠**：点击按钮展开抽屉；抽屉内提供收起按钮；再次点击开关按钮也可折叠。
- **FR3 不遮挡聊天内容**：抽屉展开时占据独立的右侧栏空间，聊天列宽度被压缩、文字让位，
  任何情况下抽屉不得覆盖聊天文字。
- **FR4 终端标签页**：抽屉内含"终端"标签，可启动真实 shell（Windows 下 PowerShell），
  支持输入命令、实时查看输出、Ctrl+C 中断、清屏、重启会话。
- **FR5 浏览器标签页**：抽屉内含"浏览器"标签，提供地址栏，可在抽屉内加载网页；
  对拒绝内嵌的站点给出提示，并提供"新窗口打开"按钮。
- **FR6 标签切换**：终端与浏览器两个标签自由切换，切换时各自状态保持。
- **FR7 主题适配**：明 / 暗主题下界面均正常显示（使用 DSH 主题 CSS 变量）。

### 非功能需求

- **NFR1** 客户端零第三方依赖；宿主仅复用 profile 依赖树中已有的 node-pty，不引入新依赖。
- **NFR2** 卸载干净：移除插件后产品恢复原状，不残留界面元素与服务。
- **NFR3** 页面刷新后插件正常恢复为折叠默认状态；终端会话随刷新重建（旧会话由宿主回收）。

## Acceptance Criteria

- [ ] **AC1 默认折叠**：打开聊天页，右上角可见开关按钮，抽屉折叠，聊天区域全宽。
- [ ] **AC2 展开不遮挡**：点击按钮后抽屉从右侧展开，聊天文字不被遮挡（聊天列变窄），按钮反映展开状态。
- [ ] **AC3 折叠恢复**：点击抽屉内收起按钮（或再次点击开关按钮），抽屉折叠，聊天恢复全宽。
- [ ] **AC4 终端可用**：终端标签出现 shell 提示符；输入 `echo hello` 回车可见输出；
      运行持续输出的命令能实时看到输出；Ctrl+C 能中断前台命令。
- [ ] **AC5 浏览器可用**：浏览器标签输入 `https://example.com` 回车，页面在抽屉内加载；
      对拒绝内嵌的站点出现提示且"新窗口打开"可用。
- [ ] **AC6 主题适配**：明暗主题切换后抽屉界面配色正常。
- [ ] **AC7 可卸载**：移除 junction 与 bundles 条目并重启后，产品恢复原状。

## Notes

- 需求确认记录：抽屉落位方案（复用官方右侧 details 栏，布局自动让位）与浏览器形态
  （地址栏 + iframe + 新窗口兜底）已与用户确认，见会话记录与 design.md。
- 本期范围外：全屏交互程序（vim/top，需网格渲染）、浏览器代理重写绕过 X-Frame-Options、
  多终端并行、抽屉状态持久化（刷新后回到折叠默认）。

# v2 迭代：终端与浏览器优化（2026-08-14）

用户确认范围：终端全部优化（性能 + 交互 + xterm.js 真终端）；浏览器导航控制 + 状态记忆 + 安全加固；
允许引入第三方依赖（NFR1 修订）。

## 功能需求（新增 / 修订）

- **FR8 终端真终端化**：终端改用 xterm.js 渲染，支持 ANSI 颜色与控制序列、逐键输入
  （shell 原生命令历史 ↑↓ / Ctrl+C / 回显）；输出量大时流畅不卡顿；面板尺寸变化后折行正确
  （resize 同步到 pty）。
- **FR9 折叠不断连**：折叠抽屉不再杀死终端会话，重新展开会话与输出保持；
  页面刷新仍会重建会话（NFR3 不变）。
- **FR10 浏览器增强**：地址栏之外提供后退 / 前进 / 刷新导航按钮；记住上次网址并在重开抽屉时
  恢复；iframe 增加 sandbox / referrerPolicy 加固。

## 非功能需求（修订）

- **NFR1（修订）**：客户端允许唯一第三方依赖 `@xterm/xterm`（经宿主 vendor 路由提供，浏览器动态
  import，无构建步骤）；宿主仍只复用 profile 已有 node-pty。
- **NFR4（新增）**：node_modules 缺失（未 pnpm install）时，终端页显示明确修复提示，宿主进程不崩溃。

## 验收标准（新增）

- [ ] **AC8**：ANSI 颜色正常显示；↑↓ 可调取历史；持续输出命令流畅；尺寸变化后折行正确。
- [ ] **AC9**：折叠再展开，终端会话与输出保持；刷新页面会话重建。
- [ ] **AC10**：访问 2+ 站点后可后退/前进；刷新按钮重载页面；重开抽屉恢复上次网址。
- [ ] **AC11**：iframe 带 sandbox/referrerPolicy；node_modules 缺失时终端页给出 pnpm install
      提示且宿主不崩。

## 范围外（v2 仍不做）

- 浏览器代理重写绕过 X-Frame-Options；多终端并行会话；抽屉状态跨刷新持久化；
  传输层不改（保持 HTTP 轮询，不引 SSE/WebSocket）。
